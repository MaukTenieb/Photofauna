# Photofauna

The pocket photo emulator of Insert Koin, by Mauk Tenieb: shoot or open a picture, stack effects, undo, save. Every file is named after the French Republican calendar (`18-vendemiaire-235_photofauna_001.png`).

**Online: https://mauktenieb.github.io/insertkoin/fotofauna.html**

The code lives in the [insertkoin](https://github.com/MaukTenieb/insertkoin) repository (`fotofauna.html`, `ik-name.js`).
